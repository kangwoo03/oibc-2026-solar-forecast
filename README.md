# OIBC 2026 태양광 발전량 예측 프로젝트

기존 베이스라인 모델을 바탕으로 AI를 활용해 개선 방법을 찾고, 모델을 학습해 발전량과 정산금을 추정한 개인 프로젝트입니다. 여러 후보의 검증 결과와 실제 제출 결과를 비교하며 최종 모델을 선택했습니다.

## 프로젝트 개요

- **진행 형태:** 개인 프로젝트
- **과제:** 태양광 발전소 253개소를 두 집합자원으로 구성하고, 집합별 하루전 시간당 발전량 예측
- **목표:** 예측 오차에 따른 페널티를 줄여 대회 정산금 지표 개선
- **정리 기준:** 2026년 11월 7일

각 집합의 설비용량은 20,000kW 이상이어야 하며, 평가 기간에는 동일한 배정을 유지해야 합니다. 정산금은 매전수익에서 예측 오차 페널티를 차감해 계산합니다. 특히 KST 11~15시에는 페널티 가중치가 커 해당 시간대의 예측이 중요했습니다.

## 진행 방식과 AI 활용

제공된 베이스라인을 출발점으로 삼았습니다. AI의 도움을 받아 개선할 수 있는 부분을 찾고, 이를 반영한 모델을 학습시켜 결과를 비교했습니다. 모델 선택과 정산금 추정 과정에도 AI를 활용했습니다.

이 프로젝트는 모델 전체를 처음부터 독자적으로 구현한 경험이 아니라, **AI를 활용해 기존 모델의 개선 후보를 탐색하고 학습 및 평가 결과를 비교한 경험**입니다. 팀 협업 없이 혼자 진행했습니다.

## 개선한 내용

### 시간 구간에 맞춘 기상 특징 추가

구름량, 기온, 자외선 예보에 인접 시각의 평균과 변화량을 추가했습니다. 한 시간 구간의 발전량을 예측할 때 구간 내 기상 변화도 반영하려는 방법입니다.

- 구간 평균: 현재 시각과 이전 시각 예보의 평균
- 변화량: 현재 시각 예보에서 이전 시각 예보를 뺀 값
- 같은 기상 지점, 예보 라운드, 대상일 안에서 연속 시각 연결
- 실제 기상 관측값이나 나중에 발행된 예보로 대체하지 않음

### 기존 앙상블의 일부 예측 갱신

기존 앙상블을 바탕으로 LightGBM 구성요소를 갱신했습니다. 최종 모델은 페널티 가중치가 큰 11~15시에 해당 구성요소의 예측 차이를 반영했습니다. 발전소의 집합 배정은 직전 모델과 동일하게 유지했습니다.

모델은 발전량을 설비용량으로 나눈 이용률을 예측한 뒤 발전소별 결과를 집합별로 합산하는 구조입니다. LightGBM의 L1 손실을 사용하고, SMP·시간대 가중치·설비용량을 학습 가중치에 반영했습니다.

## 결과와 최종 선택

| 항목 | 결과 |
| --- | --- |
| 최종 기준 모델 | settlement_interval_weather |
| 실제 제출 정산금 지표 | 6,442,352,399원 |
| 직전 제출 대비 | 약 200만 원 개선 |
| 후속 후보 settlement_interval_wb_gate | 최종 기준 모델보다 약 10만 원 하락 |

금액은 실제 수익이 아닌 **대회 평가 지표**입니다. 위 제출 결과는 참가자가 확인해 기록한 리더보드 결과를 기준으로 정리했으며, 이 저장소를 작성하면서 리더보드에 별도로 접속해 재검증하지는 않았습니다.

후속 후보는 일부 봄철 검증에서 개선됐지만 실제 제출에서는 점수가 낮아졌습니다. 따라서 실제 제출에서 더 좋은 결과를 낸 settlement_interval_weather를 최종 기준으로 유지했습니다.

## 어려웠던 점과 배운 점

검증에서 좋아진 방법이 실제 평가에서도 좋아지는 것은 아니었습니다. 기상 예보 조합이나 보정 방법에 따라 월별·계절별 결과가 달라졌습니다. AI가 제안한 방법도 적용 후 결과를 확인하고 기존 모델과 비교해야 한다는 점을 배웠습니다.

또한 같은 과거 구간을 여러 실험에서 반복해서 사용했으므로, 해당 구간의 개선을 독립적인 테스트 성능으로 볼 수는 없습니다. 일부 검증은 전체 파이프라인을 같은 시점 기준으로 재학습한 결과가 아니며, 실제 평가 실적이 없어 제출 점수 차이를 시간대별 원인으로 정확히 분해하지 못했습니다.

## 사용한 도구

Python, pandas, NumPy, LightGBM, scikit-learn을 활용한 모델 학습 및 결과 분석 환경을 사용했습니다. 개선 방법 탐색과 모델 선택 과정에서는 AI의 도움을 받았습니다.

## 공개 범위와 앞으로의 계획

이 저장소는 프로젝트 경험과 실험 결과를 정리한 문서 저장소입니다. 대회 원본 데이터, 발전소별 정보, 예측 CSV와 학습 코드는 포함하지 않았습니다. 따라서 현재 저장소만으로 모델을 실행하거나 결과를 재현할 수는 없습니다.

앞으로는 모델의 작동 원리를 더 공부하고, 실험 조건과 결과를 일정한 형식으로 기록해 어떤 변경이 도움이 됐는지 설명할 수 있도록 보완하고 싶습니다. 코드 공개는 대회 규정과 공개 가능 범위를 확인한 뒤 검토할 계획입니다.
