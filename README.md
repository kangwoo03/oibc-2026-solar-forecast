# OIBC 2026 태양광 발전량 예측 프로젝트

기존 베이스라인에 AI의 도움을 받아 개선 후보를 적용하고, 검증 결과와 대회 제출 결과를 비교한 개인 프로젝트의 문서 포트폴리오입니다.

> **현재 공개 범위는 README뿐입니다.** 원본 데이터, 학습·평가 코드, 모델 파일, 실행 환경과 실험 로그는 포함하지 않았습니다. 이 저장소만으로 모델을 실행하거나 아래 결과를 재현·독립 검증할 수 없습니다. 기술 설명과 성과는 기존 참가자 기록을 정리한 것이며, 공개 코드나 원본 평가 자료로 확인한 결과가 아닙니다.

- 프로젝트 기록 기준: 2026년 11월 7일
- 공개 구성 확인 및 문서 정리: 2026년 11월 9일

## 1. 문제와 목표

기존 프로젝트 기록에 따른 과제와 평가 조건은 다음과 같습니다. 공식 규정 원문과 세부 평가식은 이 저장소에 첨부되어 있지 않습니다.

| 항목 | 기록된 내용 |
| --- | --- |
| 진행 형태 | 팀 협업 없이 진행한 개인 프로젝트 |
| 예측 대상 | 태양광 발전소 253개소를 두 집합자원으로 구성한 집합별 하루전 시간당 발전량 |
| 집합 구성 조건 | 각 집합 설비용량 20,000kW 이상, 평가 기간 동안 동일한 배정 유지 |
| 목표 | 발전량 예측 오차에 따른 페널티를 줄여 대회 정산금 지표 개선 |
| 평가상 고려 사항 | 정산금은 매전수익에서 예측 오차 페널티를 차감하며, KST 11~15시에는 페널티 가중치가 큼 |

정산금은 **대회 평가 지표**이며 실제 매출이나 실현 수익을 의미하지 않습니다. 위 조건을 공식 규정 전체나 정확한 정산식의 대체 자료로 사용해서는 안 됩니다.

## 2. 수행 범위와 AI 활용

제공된 베이스라인을 출발점으로 개선 후보를 탐색하고, 모델 학습 및 결과 비교를 진행했습니다. 모델 전체를 처음부터 독자적으로 구현한 경험으로 제시하지 않습니다.

| 구분 | 기존 기록으로 설명할 수 있는 범위 |
| --- | --- |
| 베이스라인 활용 | 기존 모델과 앙상블을 기반으로 일부 특징과 구성요소를 변경 |
| AI 활용 | 개선 방법 탐색, 모델 선택 및 정산금 추정 과정에 도움을 받음 |
| 수행 경험 | 개선 후보를 반영한 학습, 검증·제출 결과 비교, 최종 기준 모델 선택 |
| 공개 자료로 확인할 수 없는 부분 | 직접 작성·수정한 코드의 범위, AI 생성 코드의 비중, 프롬프트·도구·모델 버전, 실행 및 검토 내역 |

AI 제안 자체를 성능 개선의 근거로 삼지 않습니다. 현재 공개 자료로는 구현의 정확성이나 AI 제안에 대한 검토 수준을 확인할 수 없으며, 개인의 독자 구현 역량을 코드로 평가하기에도 한계가 있습니다.

## 3. 기록된 개선 과정

아래는 기존 README에 기록된 설계 설명입니다. 실제 코드에서 확인한 구현 명세가 아닙니다.

### 기상 예보의 인접 시각 특징

구름량·기온·자외선 예보에 인접 시각 평균과 변화량을 추가했습니다. 한 시간 구간 안의 기상 변화를 반영하려는 접근입니다.

- 구간 평균: 현재 시각과 이전 시각 예보의 평균
- 변화량: 현재 시각 예보에서 이전 시각 예보를 뺀 값
- 연결 조건: 같은 기상 지점·예보 라운드·대상일 안의 연속 시각
- 입력 시점 원칙: 실제 기상 관측값이나 나중에 발행된 예보로 대체하지 않음

마지막 두 항목은 기록된 처리 원칙입니다. 예보 발행 시각, 결합 로직과 학습·검증 분할 코드가 공개되어 있지 않아 **데이터 누수가 없었다고 검증한 것은 아닙니다.**

### 기존 앙상블의 일부 예측 갱신

기존 앙상블의 LightGBM 구성요소를 갱신하고, 최종 모델에서는 KST 11~15시에 해당 구성요소의 예측 차이를 반영했습니다. 발전소의 집합 배정은 직전 모델과 동일하게 유지했습니다.

기록된 처리 흐름은 다음과 같습니다.

1. 기상 예보에 인접 시각 특징을 추가합니다.
2. 발전량을 설비용량으로 나눈 이용률을 예측합니다.
3. 기존 앙상블에 일부 예측 차이를 반영합니다.
4. 발전소별 결과를 집합별로 합산해 발전량과 정산금 지표를 평가합니다.

LightGBM의 L1 손실을 사용하고 SMP·시간대 가중치·설비용량을 학습 가중치에 반영했다고 기록했습니다. 세부 가중치 식, 하이퍼파라미터와 앙상블 결합식은 공개되어 있지 않으므로, 이 설명만으로 동일한 모델을 구성하거나 정산금 최적화 효과를 확인할 수 없습니다.

## 4. 결과와 근거 수준

다음 수치는 **참가자가 확인해 기존 README에 기록한 리더보드 결과**입니다. 이번 문서 정리에서는 리더보드에 별도로 접속해 재검증하지 않았습니다. 공개 저장소에는 제출 ID·평가 일시·원본 점수표·스크린샷·예측 파일이 없어 독립 검증할 수 없습니다.

| 항목 | 기존 기록 | 해석 범위 |
| --- | --- | --- |
| 최종 기준 모델 식별명 | `settlement_interval_weather` | 실험 식별명이며 공개 코드나 실행 명령이 아님 |
| 실제 제출 정산금 지표 | 6,442,352,399원 | 참가자가 기록한 대회 평가값, 실제 수익 아님 |
| 직전 제출 대비 | 약 200만 원 개선 | 직전 제출의 정확한 점수와 제출 조건은 미공개 |
| 후속 후보 `settlement_interval_wb_gate` | 최종 기준 모델보다 약 10만 원 하락 | 정확한 후보 점수와 제출 조건은 미공개 |

후속 후보는 일부 봄철 검증에서 개선됐지만 실제 제출에서는 점수가 낮아졌다고 기록했습니다. 이에 제출 결과가 더 좋았던 `settlement_interval_weather`를 최종 기준으로 유지했습니다.

이 비교는 모델 선택의 기록입니다. **직전 제출은 최초 제공 베이스라인과 동일하다고 확인되지 않았으며**, 위 차이를 최초 베이스라인 대비 개선량으로 해석할 수 없습니다. 변경별 효과를 분리한 실험도 공개되어 있지 않아 특정 특징이나 시간대 수정이 개선의 원인이라고 단정할 수 없습니다. 순위·수상 여부·일반화 성능은 이 기록으로 입증되지 않습니다.

## 5. 검증 한계와 배운 점

검증에서 좋아진 방법이 실제 제출에서도 좋아지지는 않았습니다. 기상 예보 조합과 보정 방법에 따라 월별·계절별 결과가 달라졌으며, AI 제안도 적용 후 기존 모델과 비교해야 한다는 점을 배웠습니다.

| 한계 | 결과 해석에 미치는 영향 |
| --- | --- |
| 같은 과거 구간을 여러 실험에서 반복 사용 | 해당 구간의 개선을 독립 테스트 성능으로 볼 수 없으며, 선택 과정의 과적합 가능성이 있음 |
| 일부 검증은 전체 파이프라인을 같은 시점 기준으로 재학습한 결과가 아님 | 후보 간 조건이 동일한 비교인지 확인하기 어려움 |
| 학습·검증 기간, 분할 방식, 시드와 실행 환경 미공개 | 시간 순서 준수, 실험 변동성 및 재현성 검증 불가 |
| 평가 구간의 실제 발전 실적 자료 부재 | 제출 점수 차이를 시간대별 원인으로 정확히 분해하지 못함 |
| 코드·가중치 식·원본 로그 미공개 | 누수 방지, 평가식 구현과 개별 변경의 기여도 확인 불가 |

따라서 현재 성과는 제한된 제출 비교 경험으로 설명하며, 통계적으로 검증된 개선이나 새로운 기간에서도 유지되는 성능으로 주장하지 않습니다.
